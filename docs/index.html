娘からのお知らせ

アプリの「📮 お父さんに知らせる」から届いたもの。コピーして Claude に貼れば直せます。

    お知らせの送り先

    お父さんの電話番号か、iMessage のメールアドレス。入れておくと、娘が「知らせる」を押したとき メッセージが 宛先と ぜんぶの内容が入った状態で開きます。この iPad の中にだけ保存します。
